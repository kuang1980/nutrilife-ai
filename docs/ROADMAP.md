# Scoped roadmap

Time ranges are individual-developer planning estimates, not delivery promises. Clinical and integration review can change the sequence.

| Stage | Scope | Exit gate |
| --- | --- | --- |
| Now: partner prototype | Delivered local closed-loop scenario and project docs | Rehearsed demo, synthetic labels, deterministic reset, passing domain checks |
| 1: harden foundation (1–2 weeks) | Typed domain records, semantic state validation, structured events, UI regression harness, portion correction, improved keyboard/focus behavior | Both meal branches and decline flow tested at mobile/desktop; invalid states rejected |
| 2: validate usefulness (2–3 weeks) | Interview 5–8 consenting working adults; partner/dietitian content review; prototype usability tests | Evidence that disrupted meals and coordination effort are meaningful; revise or stop if hypothesis fails |
| 3: narrow pilot (4–6+ weeks) | Authentication, consent, verified food catalog, read-only free/busy adapter, reminder delivery/preferences, deletion/export, security review | Qualified safety/privacy review; permission revocation and provider failures tested; no real health data before review |
| 4: evaluate before expanding | Small opt-in feasibility pilot, transparent metrics and adverse-feedback review | Defined feasibility/retention thresholds agreed prospectively with partner; no efficacy claims from demo |

Defer grocery ordering, photo recognition, wearables, continuous chat, family plans, micronutrient optimization and clinician-facing records until the core loop proves useful. First production integration should be free/busy context plus reminder orchestration, not broad calendar scraping. A standalone no-calendar manual “my day changed” action remains a valid fallback.

Partner roles to propose: clinical content reviewer; voluntary study recruitment; feedback on distribution and procurement. Founder roles: product interviews, scoped build, instrumentation design and privacy-preserving operational plan. Agree responsibilities before a pilot.
